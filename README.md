Dog Lovers é um aplicativo Android desenvolvido para amantes de cachorros. O app apresenta uma lista de diferentes raças, com nome, curiosidades e imagens. A aplicação utiliza RecyclerView para organizar os cachorros, Glide para carregar imagens por URL e possui navegação entre a tela inicial, lista e detalhes de cada cachorro. Também permite visualizar as informações de cada item e removê-lo da lista através de um clique longo com confirmação.
